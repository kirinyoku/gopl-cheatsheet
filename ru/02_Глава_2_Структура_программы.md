## 2.1. Имена: экспорт и соглашения

### Правило первой буквы (Экспорт)
В Go нет ключевых слов `public`, `private` или `protected`. Доступность сущности определяется регистром её первой буквы:
* **Заглавная буква** (`Print`, `User`, `ContentType`) $\to$ **экспортируемая** (видна внешним пакетам, Public).
* **Строчная буква** (`calculate`, `user`, `internalState`) $\to$ **неэкспортируемая** (доступна только внутри своего пакета, Private).
* **Имена пакетов** всегда пишутся строчными буквами в одно слово (`bytes`, `json`, `tempconv`).

### Стиль именования CamelCase
* В Go принят `camelCase` и `PascalCase` (не `snake_case`).
* **Акронимы сохраняют единый регистр**: пишите `serveHTTP`, `escapeHTML`, `userID`, `urlPath` (вместо `serveHttp`, `escapeHtml`, `userId`, `url_path`).
* **Правило длины**: *«Чем меньше область видимости переменной, тем короче её имя»* (локальный счетчик — `i`, читатель — `r`, буфер — `b`).

## 2.2. Четыре вида объявлений

На уровне пакета доступны ровно 4 ключевых слова объявления:
1. `var` — переменные
2. `const` — константы
3. `type` — именованные типы
4. `func` — функции

> [!NOTE]
> На уровне пакета порядок объявлений **не имеет значения**: функции и типы могут ссылаться друг на друга независимо от того, выше или ниже они описаны в исходном файле.

> [!NOTE]
> **Актуальность (Go 1.18+):** набор ключевых слов не изменился, но у объявлений `func` и `type` появились параметры типов (дженерики), которых в книге нет:
> ```go
> func Map[T, R any](s []T, f func(T) R) []R // обобщённая функция
> type Set[T comparable] map[T]struct{}      // обобщённый тип
> ```

## 2.3. Переменные, указатели и управление памятью

### Нулевые значения (Zero Values)
В Go память всегда инициализирована. Если переменная объявлена без явного значения, она гарантированно получает нулевое значение:

| Тип данных | Нулевое значение (Zero Value) |
| :--- | :--- |
| Числа (`int`, `float64`, `byte`) | `0` |
| Булевы (`bool`) | `false` |
| Строки (`string`) | `""` (пустая строка) |
| Указатели, срезы, мапы, каналы, интерфейсы, функции | `nil` |
| Структуры (`struct`) | Все поля рекурсивно заполнены нулями |

### Краткое объявление (`:=`)
Оператор `:=` используется **только внутри функций**:
```go
in, err := os.Open("in.txt")     // объявляет in и err
out, err := os.Create("out.txt") // объявляет out, а err переиспользует
```

> [!IMPORTANT]
> Для переиспользования существующей переменной слева от `:=` **хотя бы одна переменная обязана быть новой**. Если все переменные слева уже объявлены в текущем блоке, возникнет ошибка компиляции.
> Переменные из **внешнего** блока при этом не переиспользуются — `:=` молча создаст новые с затенением внешних (см. 2.7).

---

### Указатели (`&` и `*`)
* `&x` — взятие адреса переменной (тип `*int`).
* `*p` — разыменование (доступ к значению по адресу).
* Нулевое значение любого указателя — `nil`.

```go
func createPointer() *int {
    v := 42
    return &v // В C/C++ это висячий указатель, в Go — абсолютно безопасно!
}
```

### Анализ побега в кучу (Escape Analysis)
Где будет жить переменная — **на стеке или в куче** — автоматически определяет компилятор:
* Если переменная локальна и не используется после возврата из функции $\to$ размещается на быстром **стеке**.
* Если адрес переменной возвращается наружу или сохраняется в долгоживущей структуре $\to$ переменная «убегает в кучу» (**escapes to heap**) и отдается под контроль сборщику мусора.

*Функция `new(T)`* выделяет память под тип `T`, заполняет нулями и возвращает указатель `*T` (синтаксический сахар для `var dummy T; return &dummy`).

## 2.4. Присваивания и идиома comma-ok

### Множественное присваивание (Tuple Assignment)
Все выражения в правой части вычисляются **до** изменения переменных слева, что позволяет обменивать значения без промежуточной переменной:
```go
x, y = y, x // безопасный обмен значениями
```

### Идиома «comma-ok»
Используется для безопасного получения данных с признаком успеха:
```go
val, ok := m[key] // ok == true, если ключ реально присутствует в map
val, ok := x.(T)  // ok == true, если тип интерфейса соответствует T
val, ok := <-ch   // ok == false, если канал закрыт и пуст
```

## 2.5. Пользовательские именованные типы (`type`)

Объявление нового типа позволяет создать строгую границу между логически разными сущностями, даже если они имеют одинаковое базовое представление:

```go
type Celsius float64
type Fahrenheit float64

var c Celsius = 100
var f Fahrenheit = 212

// c = f          // ОШИБКА: разные типы!
// if c == f {}   // ОШИБКА: нельзя сравнивать разные шкалы!
```

### Связывание методов с типами
Методы можно привязать к любому именованному типу, **объявленному в вашем пакете** (расширить тип из чужого пакета нельзя), например строковое представление `String()` для автоформатирования в `fmt`:

```go
func (c Celsius) String() string {
    return fmt.Sprintf("%g°C", c)
}
```

## 2.6. Пакеты, файлы и функции `init()`

* **Структура**: Все файлы с кодом в одной папке принадлежат одному пакету и видят объявления друг друга без импортов.
* **Порядок инициализации**: Зависимости инициализируются снизу вверх; пакет `main` инициализируется последним.
* **Порядок внутри пакета**: сначала инициализируются переменные уровня пакета (в порядке зависимостей между ними), затем вызываются `init()`; при этом файлы компилятор обрабатывает в алфавитном порядке.

### Функции инициализации `init()`
```go
func init() {
    // предварительный расчет таблиц, проверка окружения
}
```
* Вызываются рантаймом автоматически при старте программы.
* Не принимают аргументов, ничего не возвращают, не могут быть вызваны вручную.
* В одном пакете и файле может быть несколько функций `init()`.

## 2.7. Область видимости (Scope) и затенение переменных (Shadowing)

### Главное различие
* **Область видимости (Scope)** — блок исходного текста, где имя доступно компилятору (время компиляции).
* **Время жизни (Lifetime)** — период нахождения переменной в памяти (рантайм).

> [!CAUTION]
> **Опасность непреднамеренного затенения переменных**:  
> Случайное использование `:=` во внутреннем блоке создает **новую локальную переменную**, оставляя внешнюю неинициализированной:
>
> ```go
> var cwd string // переменная уровня пакета
>
> func init() {
>     // ОШИБКА: := создал ЛОКАЛЬНУЮ cwd, а глобальная осталась пустой ("")!
>     cwd, err := os.Getwd() 
>     if err != nil {
>         log.Fatal(err)
>     }
> }
> ```
>
> **Правильное решение**:
> ```go
> var cwd string
>
> func init() {
>     var err error
>     cwd, err = os.Getwd() // обычное присваивание в глобальную переменную
>     if err != nil {
>         log.Fatal(err)
>     }
> }
> ```

## 6.1. Объявления методов и получатели (Receivers)

Метод в Go — это функция с дополнительным параметром перед именем — **получателем (receiver)**, который привязывает её к конкретному типу:

```go
type Point struct{ X, Y float64 }

// Обычная функция:
func Distance(p, q Point) float64 { ... }

// Метод типа Point:
func (p Point) Distance(q Point) float64 {
    return math.Hypot(q.X-p.X, q.Y-p.Y)
}
```

### Ключевые правила

* **Имя получателя**: В Go **нет ключевых слов `this` или `self`**. Принято использовать короткое имя из 1–2 букв (первая буква типа: `p` для `Point`, `c` для `Client`).
* **Методы для любых именованных типов**: Методы можно привязывать к структурам, числам, булевым, строкам, срезам, мапам, каналам и функциям:
  ```go
  type Path []Point

  func (path Path) Distance() float64 { ... } // метод для пользовательского среза
  ```
* *Ограничение*: тип должен быть объявлен в том же пакете, а его базовый тип не должен быть указателем или интерфейсом.

## 6.2. Получатели-значения vs Получатели-указатели (`*T`)

```go
func (p *Point) ScaleBy(factor float64) {
    p.X *= factor
    p.Y *= factor
}
```

### Когда использовать указатель `*T`:

1. Если метод должен **изменять поля объекта**.
2. Если структура велика и нужно **избежать дорогостоящего копирования**.

> [!IMPORTANT]
> **Правило согласованности**: Если хотя бы один метод типа требует указатель `*T`, то **все остальные методы этого типа также объявляются с получателем `*T`**.

### Автоматическое взятие адреса и разыменование

Go автоматически преобразует вызовы:
* На значении `p` вызов `p.ScaleBy(2)` автоматически компилируется как `(&p).ScaleBy(2)`.
  **Оговорка**: это работает только для *адресуемых* значений (переменных). Вызвать метод по указателю для элемента мапы (`m["k"].ScaleBy(2)`) или результата функции нельзя — ошибка компиляции.
* На указателе `pptr` вызов `pptr.Distance(q)` автоматически компилируется как `(*pptr).Distance(q)`.

### `nil` как допустимый получатель

Метод может безопасно вызываться на `nil`-указателе, если логика метода это предусматривает:

```go
type IntList struct {
    Value int
    Tail  *IntList
}

// nil представляет пустой список
func (list *IntList) Sum() int {
    if list == nil {
        return 0 // безопасная обработка nil
    }
    return list.Value + list.Tail.Sum()
}
```

*Пример из стандартной библиотеки*: `url.Values(nil).Get("key")` возвращает пустую строку `""` без паники.

## 6.3. Композиция вместо наследования (Встраивание структур)

В Go нет наследования классов. Повторное использование методов строится на **композиции через анонимные поля**:

```go
type Point struct{ X, Y float64 }

func (p *Point) ScaleBy(factor float64) {
    p.X *= factor
    p.Y *= factor
}

type ColoredPoint struct {
    Point // встраивание Point
    Color color.RGBA
}
```

* **Продвижение (Promotion) методов**: Методы `Point` автоматически доступны у `ColoredPoint`:
  ```go
  var cp ColoredPoint
  cp.ScaleBy(2) // вызывает Point.ScaleBy(&cp.Point, 2)
  ```
* **Важное отличие**: `ColoredPoint` **не является** `Point` (это не полиморфизм наследования). Передать `cp` в функцию, ожидающую `Point`, без явного `cp.Point` нельзя.

### Удобный паттерн с мьютексом:

```go
var cache = struct {
    sync.Mutex // встраивание мьютекса
    data       map[string]string
}{
    data: make(map[string]string),
}

func Lookup(key string) string {
    cache.Lock() // метод Lock() продвинут из sync.Mutex
    defer cache.Unlock()
    return cache.data[key]
}
```

## 6.4. Значения-методы и выражения-методы

Методы можно сохранять в переменные и передавать как функции:

### 1. Значение-метод (Method Value)

Привязка к конкретному экземпляру объекта:

```go
p := Point{1, 2}
distanceFromP := p.Distance // func(Point) float64

fmt.Println(distanceFromP(q)) // p подставляется автоматически
```

*Идеально для колбэков*: `time.AfterFunc(time.Second, rocket.Launch)`.

### 2. Выражение-метод (Method Expression)

Функция с явным первым аргументом-получателем:

```go
dist := Point.Distance    // func(Point, Point) float64
scale := (*Point).ScaleBy // func(*Point, float64)

dist(p, q)
scale(&p, 2)
```

## 6.5. Инкапсуляция: сокрытие деталей реализации

* **Единица инкапсуляции — ПАКЕТ, а не класс/структура**:
  * Имя с **заглавной буквы** $\to$ экспортируется (Public).
  * Имя со **строчной буквы** $\to$ скрыто внутри пакета (Private).
  * Все функции и методы внутри одного пакета имеют полный доступ к приватным полям.
* **Стиль геттеров и сеттеров в Go**:
  * Геттеры пишутся **без префикса `Get`**: `client.Timeout()`, `logger.Prefix()`.
  * Сеттеры пишутся с префиксом `Set`: `logger.SetPrefix(p)`.
